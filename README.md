## Academic Projects Repository

This repository serves as a structured collection of academic and independent projects developed during my AAS in Computer Software, BSc in Software Engineering, and two separate MSc programs — the first MSc in Computer Systems Architecture and the second MSc in Artificial Intelligence and Robotics — as well as independent research work conducted after graduate studies.

Taken together, the projects in this repository reflect a gradual conceptual trajectory rather than a set of isolated academic exercises. The earlier stages emphasize system implementation, low-level design, and algorithmic problem solving, while later stages increasingly focus on modeling, inference, and learning-based approaches to data-driven problems. Across this progression, the emphasis shifts from constructing functional systems toward understanding the underlying structure of data, the assumptions embedded in computational models, and the trade-offs involved in complex decision spaces. This evolving focus provides a coherent narrative that connects foundational system-level work with more recent efforts in statistical modeling, machine learning, and intelligent data analysis.

The materials are organized by academic level and subject area to ensure clarity, traceability, and long-term reference.

### 💠 BSc Final Project Notes

This repository includes my BSc final project, titled **Implementation of the Mano Basic Computer Using the VHDL**. The project showcases a complete structural and behavioral design and can be simulated in ModelSim using the provided `test.do` script.

However, the corresponding project report is not publicly available and is therefore not included in this repository. For academic inquiries or access requests, please contact the author directly.

### 💠 Thesis Notice

My first MSc thesis, titled **Power–Delay Optimization in VLSI Arithmetic Circuits Using Multi-Objective Evolutionary Algorithms**, is referenced in this repository for completeness of the academic record.

Due to institutional and supervisory restrictions, the thesis document, source code, and related materials are not publicly available and are therefore not included in this repository.

### 💠 Repository Note

This repository is a curated public archive of academic coursework projects completed over multiple academic years. To maintain a clean, flat, and accessible structure, this repository is periodically re-initialized. Therefore, the repository creation date and its single-commit history reflect the latest archival and maintenance process rather than the original development timeline of each individual project.
